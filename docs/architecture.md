# Architecture

ProofLedger separates deterministic financial authority from probabilistic assistance.

```text
Source files
  -> validation and normalization
  -> immutable finance objects and events
  -> deterministic matching and controls
  -> calibrated candidate sets
  -> minimum-evidence review
  -> journal proposals
  -> proof certificates and close pack
```

The LLM cannot accept matches, approve journals, pass controls, or close an accounting period.
